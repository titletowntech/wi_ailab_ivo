# Flow Data Tab

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-management/flow-run-information/flow-data-tab
> Captured directly from rendered HTML: 2026-08-14

When you run a flow with a Cache Event trigger, you can view
        cache write data from the connector's data object from the Data tab. The Data tab only
        displays the data selected in the cache writer, as this data is internally cached within the
        workspace.

Open a flow and select Data to access the
            flow's Data page.

You can use this page to troubleshoot or rerun flows that failed. For more information,
            see [Trigger Types and Testing](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/test-a-flow#task-e2edb542-d8db-4278-8dcc-ac1f626f502c--en__flow_testing).

Though similar to the data found with a cache object, all
            resources are available in the Quick Searches dropdown menu. You
            do not have to select a connection or cache object when accessing the data from the
            flow.

Select the data for your search to display the records found matching the
            search. You can modify the date searched, add a filter, or add columns to the records to
            help narrow the results.

Select a result to see its [Object Record Detail](https://help.trimble.com/doc/app-xchange/app-xchange/data-explorer/cache-explorer/object-record-detail). For any records that are used
            in active flows, select the dropdown icon at the end of the result to run or view the
            flow.
