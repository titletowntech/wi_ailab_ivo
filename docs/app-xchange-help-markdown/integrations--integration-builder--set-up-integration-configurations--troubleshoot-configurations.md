# Troubleshoot Configurations

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/set-up-integration-configurations/troubleshoot-configurations
> Captured directly from rendered HTML: 2026-08-14

Review this topic when troubleshooting errors with
        configurations.

- If you edit your integration configuration out of sync with
                      your flow configuration you may see a type mismatch and be unable to syncronize
                      the integration. In that case, you would see an error message highlighting which
                      flow has an invalid configuration setting.
