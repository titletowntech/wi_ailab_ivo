# Details, Usage, and Activities

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/connections/base-connections/details-usage-and-activities
> Captured directly from rendered HTML: 2026-08-14

The ![connectors icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/40226ac9-8020-4722-8766-d9586b0879c5.svg) Connectors tab within an integration lists all base
        connections created for the integration as well as the connector for which it is used. The
        base connection details display the connection details defined for the base
        connection.

You can only change by or delete a base connections if you
            are the owner and there are no integrations using it. Select Delete Base Connection to remove it.
            If you change or delete it, App Xchange
            displays the number of connections affected by the change.

Select Usage to see connections that are extending the base connection,
            including the account that owns it and its connection status.

Select the name of a connection to access the details of the
            connection extending the base connection. You can only change or see the details of
            connections defined by your account. You can only modify connections you own, though you
            may be able to view connection details depending on your permissions.

Select Activity Log to see the base configuration, when it was created,
            and if anything changed.
