# Populate Data for a Feature

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/populate-data-for-a-feature
> Captured directly from rendered HTML: 2026-08-14

Some integration features require an initial data population
        so the data can properly sync between systems.

        You must have an integration with a functioning connection
            to complete these steps.
1. Depending on the workspace type, select ![integration workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/476c5b53-43e4-4db2-8d78-2a882a193df2.svg) Integration Workspaces or ![automation workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/4bd37e33-bd30-44e4-8645-f6304e42159b.svg) Automation Workspaces.The workspace
                      opens.
2. Select the workspace's ![Jobs icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/09d86dda-0fd5-4de0-b1d2-8e270426ccbf.svg) Jobs tab.
                  The Jobs page opens.
3. In the Onboarding Feature Schedules
                      section, select the blue play icon to run the feature schedule. Do *not*
                      select Activate, as
                      you don’t want to activate the feature yet.
4. Select Yes to confirm that you want to run the sequence.
5. Select the ![Job History icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/02d2e899-a51b-47cb-b3dd-8aff9c5df5ca.svg) Job History tab.

  Here you can monitor the services that are running as a
                          part of that job and view the progress.
6. Refresh the page to see if the job has finished. Depending on how much data there is to cache write, this may take several minutes.  Once the schedule has finished, the service displays a status of Finished and an End Date.
7. Select a job to open the log records for that job. The first time you run the schedule, the new records will display. You should now validate the data.
