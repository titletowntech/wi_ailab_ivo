# Account Activity Log

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/account-activity-log
> Captured directly from rendered HTML: 2026-08-14

The account Activity Log records all changes made to your
        company account by all users.

To access the account Activity Log, select ![activity log icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/65a729db-df28-40c9-a8b3-4bb1fcfab5c8.svg) Activity Log on the lefthand menu.

You can filter log entries by
                                activity, user, and date. Select an option from the dropdown list to
                                add the filter.

To see what was changed, expand an
                                item to view its details, or select Expand All.

        Each log entry includes:
- The date and time of change.
- The category of change.
- The user who made the change.
- A preview of the change.

The account Activity Log tracks the following activities:

- Accept Integration Deployment Invite
- Account Created
- Base Connection Created
- Base Connection Updated
- Base Connection Deleted
- Connection Added
- Connection Connected
- Connection Deleted
- Connection Disconnected
- Connection Removed
- Connection Updated
- Create Integration Deployment
- Delete Integration Deployment
- Guest left the account
- Invite Accepted
- Invite Created
- OAuth Client Added
- OAuth Client Deleted
- OAuth Client Updated
- App Xchange Agent Added
- App Xchange Agent Updated
- App Xchange Agent
                  Removed
- Reject Integration Deployment Invite
- Resent Integration Deployment Invite
- Sent Integration Deployment Invite
- Update Integration Deployment
- User Locked
- User Unlocked
- User Assigned To Account
- User Created
- User Removed From Account
- User Left The Account
- Workspace Archived
- Workspace Created
