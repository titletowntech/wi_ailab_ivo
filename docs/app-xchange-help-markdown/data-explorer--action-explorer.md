# Action Explorer

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/data-explorer/action-explorer
> Captured directly from rendered HTML: 2026-08-14

A workspace's ![action explorer icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/eef8e106-1862-4454-b22b-eae7aa476425.svg) Action Explorer tab displays actions generated by your workspace and integrations.

The ![action explorer icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/eef8e106-1862-4454-b22b-eae7aa476425.svg) Action Explorer displays all actions by default. You can filter your view by App, Action Path,
            Created Date, Modified Date, Id, and Status. This is a valuable troubleshooting tool, as
            you can compare failed actions against jobs and schedules to understand why they
            failed.

You can filter the Actions Explorer results by the following statuses
            status to display only Successful, Failed, Canceled, or Queued actions. For more information, see the [Step Outputs](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-steps/connector-action-flow-step#concept-0878a520-e442-4c7e-864c-71dcc26aefd5--en__outputs_section) section of the Connector Action flow step.

You can filter by Created Date or Modified Date. If you know an
            action's ID, you can filter by ID (single or multiple).

If one or more flows are set to use a relevant action close out trigger, you can view them with the dropdown.

Select an action to see the Action Detail view, where you can view the
            action’s JSON payload. This view is only available for action instances from the last 90
            days (3 months).

Note: If you are the flow author, you can toggle whether
                                    hidden values are visible in the cache and action explorers via
                                    the eye
                                                icon. Hidden values include personally
                                    identifying information and financial information.
