# Workspace Cache

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/data-explorer/cache-explorer/workspace-cache
> Captured directly from rendered HTML: 2026-08-14

The workspace ![cache explorer icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/a43dbd04-a23b-4bb9-9584-8bfae00211f9.svg) Cache Explorer, also called Cache, allows you to focus on one object to view.

To access the cache explorer, open your workspace and select
            the ![cache explorer icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/a43dbd04-a23b-4bb9-9584-8bfae00211f9.svg) Cache Explorer tab.

To begin, select a connector (A) and a cache object (B) to
            view. The Cache Explorer displays a table view of all data records for the selected
            Cache Object/resource. You can filter the records by Modified Date (C). To filter by a
            property, select Add Filter
            (D) and select the desired property, operator, and value. Within the table header, you
            can show and hide any properties associated with the record (E).

Select a record to see its [Object Record Detail](https://help.trimble.com/doc/app-xchange/app-xchange/data-explorer/cache-explorer/object-record-detail). This displays all of the properties of the record as well
            as its associated actions and flows.

## View a Cache Object

Follow these steps to view a specific data object in the
        cache.

1. In the Cache Explorer page, select the appropriate
                      connector from the Select a connector dropdown.
2. select the appropriate cache object from the Select a cache
                          object dropdown.
3. If needed, filtering the records by Modified Date to
                      refine your results.
4. If needed, filter by a property by selecting Add Filter.
                      Select Search when you are done adding filters.
The cache object results are listed.
        You can add a column
            to show or hide any properties associated with the record. Select the Show/Hide Properties dropdown and
            select a property.
