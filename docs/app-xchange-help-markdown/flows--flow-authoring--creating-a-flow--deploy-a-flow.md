# Deploy a Flow

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/deploy-a-flow
> Captured directly from rendered HTML: 2026-08-14

Once a flow is ready, you can test it on staging before
        promoting it to main.

1. In the flow, select Save and Deploy to Staging
                      and confirm. You can make a comment when doing so.

                      Tip: Alternatively, select the arrow and
                              Save Draft
                              Version to add the new step to your flow.
2. Test your changes to verify the flow runs as
                      expected.
3. Select Promote to Main, review the
                      number of workspaces to be updated, and confirm. You can make a comment when
                      doing so.
The flow is deployed to main. All workspaces that
            registered your flow will be updated to use the latest version of the flow.
