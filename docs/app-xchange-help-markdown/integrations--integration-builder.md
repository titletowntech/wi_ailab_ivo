# Integration Builder

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder
> Captured directly from rendered HTML: 2026-08-14

The ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder is the essential component for building integrations on App Xchange.

Building an integration is an iterative process, so you will likely jump between steps
            when first setting one up.

Before building an integration, you should review the following resources:

- [Best Practices for Integration Design](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/best-practices-for-integration-design)
- [Best Practices for Integration Building](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/best-practices-for-integration-building)

        Note: Avoid writing unmanaged test flows in your development workspace
            immediately. Connectors are only registered and enabled once you create, sync, and
            activate your first feature, which must be done in a deployment workspace.To build an integration, complete the following steps:
1. [Add an Integration](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-an-integration) to your
                      account.
2. [Add Connectors](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-connectors) to your integration.
3. [Add Features](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features) to your integration.
  1. [Add Services to a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features/add-services-to-a-feature).
  2. [Add Flows to a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features/add-flows-to-a-feature).
  3. [Add Flow Templates to a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features/add-flow-templates-to-a-feature).
4. [Set Up Integration Configurations](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/set-up-integration-configurations).
5. [Sync
                          the integration definition](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/sync-an-integration-registration) with your development workspace to
                      register the integration.
6. Test the integration in your [Development Workspaces](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/development-workspaces).
7. [Register the integration](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration) to a workspace.
