# Creating a Flow

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow
> Captured directly from rendered HTML: 2026-08-14

Creating a flow is a multi-step process that requires planning
        and iteration.

Before building your flow, consider what you want to accomplish with it and what kind of
            data you will handle. Review the [Best Practices for Flow Design](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/best-practices-for-flow-design).
            Once you have a good idea of what your flow needs to do, you can start building the
            necessary components.

1. [Add a Flow](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/add-a-flow)
2. [Add a Trigger](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/add-a-trigger)
3. [Add Flow Steps](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/add-or-edit-flow-steps)
4. [Deploy a Flow](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/deploy-a-flow)

To try these steps out for yourself, follow the steps in [Create Your First Flow](https://help.trimble.com/doc/app-xchange/app-xchange/getting-started/create-your-first-flow) to create a flow that
            doesn't require any connectors to be run.

After you create your flow, you can do the following:

- Set Up Flow Configurations. For more information,
                      see [Using Configurations in Flows](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/using-configurations-in-flows).
- [Test a Flow](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/test-a-flow)
- [Troubleshoot a Flow](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/troubleshoot-a-flow)
- Revise a Flow. For more information, see [Flow History](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/flow-history).
