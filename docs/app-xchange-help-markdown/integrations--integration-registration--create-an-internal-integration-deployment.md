# Create an Internal Integration Deployment

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-an-internal-integration-deployment
> Captured directly from rendered HTML: 2026-08-14

Follow these steps to deploy an integration internally to
        a new company or business unit.

        Your account must have
            the Internal Integrations feature and an operational integration to complete these
            steps.

1. Select ![my deployments icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/ffa7bfce-b578-4e01-a650-d89b2c5490d4.svg) My Deployments.
2. Select New Deployment.
                  The New Integration Deployment window opens.
3. Select the integration you want to deploy, then select Next.
4. Enter a descriptive workspace name in the Workspace name field, then select Complete.
                  As a best practice, follow this naming convention when adding a
                          workspace: Company Name: Connector 1 <> Connector
                          2.

        A new integration deployment owned by your
            account is created. It displays in both your ![my deployments icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/ffa7bfce-b578-4e01-a650-d89b2c5490d4.svg) My Deployments and ![integrations icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integrations tabs in your workspace.Note: It may take several minutes for your integration deployment to
            display.
        [Configure Connectors](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/configure-connectors)
