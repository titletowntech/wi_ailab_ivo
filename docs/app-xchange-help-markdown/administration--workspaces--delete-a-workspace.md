# Delete a Workspace

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces/delete-a-workspace
> Captured directly from rendered HTML: 2026-08-14

Workspaces can be permanently deleted while leaving the account intact.

You must be an Administrator to delete a workspace. You must remove all active flows, integrations, and schedules to delete a workspace.

            Note: Development workspaces cannot be deleted.

1. Depending on the workspace type, select ![integration workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/476c5b53-43e4-4db2-8d78-2a882a193df2.svg) Integration Workspaces or ![automation workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/4bd37e33-bd30-44e4-8645-f6304e42159b.svg) Automation Workspaces.The workspace
                      opens.
2. Delete all integration features. Repeat these
                      steps for each feature.

  1. Select the workspace's ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integrations tab.
                            The workspace's
                                Integrations page opens.
  2. Select the pencil icon next to Features.
  3. Select Delete.
  4. Select Delete again to
                                confirm.
3. Archive all registered flows in the workspace.
                      Repeat these steps for each registered flow.

  1. Select the workspace's ![flows icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/6527fef5-240b-4327-8e72-7357efa67678.svg) Flows tab.
                            The workspace's Flows
                                page opens.
  2. Select a registered flow. The flow
                                opens.
  3. Select the gear icon.
  4. Select Archive and
                                confirm.
4. Decativate all jobs in the workspace. Repeat these
                      steps for each job.

  1. Select the workspace's ![build edi flow step icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/a0f89d51-e4d3-468d-8d88-135075b517bc.svg) Jobs tab.
                            The workspace's Jobs
                                page opens.
  2. Select Inactivate on each
                                job in Workspace Schedules.
  3. Select Yes to confirm.
5. Select the pencil icon to the right of the
                      workspace name.
                  The Edit Workspace drawer opens.
6. Select Delete Workspace.
7. Enter the name of the workspace to confirm then select Delete.

Your workspace is deleted.
