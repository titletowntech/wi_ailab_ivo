# Add a Trigger

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/add-a-trigger
> Captured directly from rendered HTML: 2026-08-14

In order to add a trigger to your flow, you must first
        determine the appropriate type of trigger to meet your goal.

         For an explanation of trigger types, see [Triggers](https://help.trimble.com/doc/app-xchange/app-xchange/flows/triggers).
                Once you have identified what trigger your flow
                    needs, follow the appropriate instructions to add it to your flow:

- [Add an Action Close Out Trigger](https://help.trimble.com/doc/app-xchange/app-xchange/flows/triggers/add-an-action-close-out-trigger)
- [Add a Cache Event Trigger](https://help.trimble.com/doc/app-xchange/app-xchange/flows/triggers/add-a-cache-event-trigger)
- [Add an On-Demand Trigger](https://help.trimble.com/doc/app-xchange/app-xchange/flows/triggers/add-an-on-demand-trigger)
- [Add a Work Request Batch Ready Trigger](https://help.trimble.com/doc/app-xchange/app-xchange/flows/triggers/add-a-work-request-batch-ready-trigger)

            Once you have added a trigger to your flow, you can
            construct your flow using flow steps. See [Add or Edit Flow Steps](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/creating-a-flow/add-or-edit-flow-steps).
