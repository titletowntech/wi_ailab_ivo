# Job History

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/jobs-and-schedules/job-history
> Captured directly from rendered HTML: 2026-08-14

A workspace's ![Job History icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/02d2e899-a51b-47cb-b3dd-8aff9c5df5ca.svg) Job History tab displays a list of runs for scheduled and unscheduled jobs.

Select the appropriate tab to see the information and the historical details.

- The Scheduled tab shows the jobs that were run on the schedule.
- The Not Scheduled tab shows the jobs that were run manually or because of the action processing of a flow.

Schedules require the prior schedule of the same object to finish before a new schedule can start. The new schedule will be either skipped or canceled if the prior schedule is still running. A long-running schedule can happen when there are many records being processed for an object.
