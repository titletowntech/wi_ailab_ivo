# Sign In to App Xchange

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/users/sign-in-to-app-xchange
> Captured directly from rendered HTML: 2026-08-14

App Xchange user accounts are created and managed using Trimble ID.

You can access the App Xchange
      platform at [app.xchange.trimble.com](https://app.xchange.trimble.com/). All users must create a Trimble ID when they are first invited to the platform.
        Trimble ID accounts are used across multiple
        Trimble products and are, therefore,
      managed separately from the App Xchange
      platform.

These pages on Trimble Help include additional
                                    details about Trimble ID:

- [Create a Trimble ID](https://apim.viewpointplatform.com/help/v1/contents/urn:contentId:accountservices_001:accountservices:accountservices)
- [Sign in with Trimble ID](https://apim.viewpointplatform.com/help/v1/contents/urn:contentId:accountservices_002:accountservices:accountservices)
- [Manage My Trimble ID Profile](https://apim.viewpointplatform.com/help/v1/contents/urn:contentId:accountservices_003:accountservices:accountservices)
