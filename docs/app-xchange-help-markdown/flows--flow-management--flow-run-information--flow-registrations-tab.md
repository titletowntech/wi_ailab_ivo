# Flow Registrations Tab

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-management/flow-run-information/flow-registrations-tab
> Captured directly from rendered HTML: 2026-08-14

The Registrations tab displays on the Flow page for any flow
        you authored.

        Open a flow and select Registrations to access
            the flow's Registrations page.Note: You must
                be a flow author and a user on the account to view the Registrations tab.

The Registrations tab tracks all workspaces where the flow
            is registered and indicates whether it occupies the staging or main deployment slot. It
            also allows you to manage which version of that flow runs in registered workspaces.

Select a workspace to see the flow registration for that workspace. To see the
            flow registration for a workspace you are already viewing, select the Edit tab
            instead.

Use the search bar to find a specific workspace. Select
                Main or Staging next to the search bar
            to show only registrations on that branch.
