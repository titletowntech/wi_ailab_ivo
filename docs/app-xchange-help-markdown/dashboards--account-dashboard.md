## Completed Flow Runs

You can filter and sort the Completed Flow Runs data in several
                ways. For information about other common filters, see [Dashboards](https://help.trimble.com/doc/app-xchange/app-xchange/dashboards).

Select the My
                    Workspaces dropdown to display flow run results for a specific
                workspace owned by your account. This includes customer workspaces that include the
                integration.

Select the My
                    Integrations dropdown to display flow run results for a specific
                integration managed by your account.

The account table lists the items in the dashboard
                individually. You can view the list either by workspace or by flow.

- Workspaces: All the workspaces that have the flow registered to
                      it. Select a workspace to see all the flows being run in that workspace. Select
                      a flow to see the flow run status details.
- Flow: All the flows that have been run from this workspace.
                      Select a flow to see the workspace details for the flow. Select the flow to see
                      the flow run status details.

## Schedule Health

The Schedule Health widget displays data about
                                schedule runs over the last 31 days. The graph displays a
                                visualization of the schedule and statuses over time. The table
                                displays schedule details including schedule name, time of the last
                                finish, health status, and the health trend of the last 10
                                runs.

Select the plus sign
                                next to the workspace to see the details of each schedule.

The dots are a quick glance at the last ten schedule runs.
                                Schedules being run as part of features in maintenance or onboarding
                                mode are tagged as such.

The Last
                                Finished column shows the date when the schedule was last
                                finished.

The Status column shows
                                the results of the last 10 available runs. The schedule can have
                                several statuses.

- Archived: The
                                                  schedule is no longer in use.
- Healthy: All of the
                                                  displayed runs were successful.
- Inactive: The
                                                  schedule is currently turned off.
- Unhealthy: At least
                                                  one of the displayed runs was unsuccessful.

The Trends column shows an at-a-glance look at
                                the last run.

- Degrading: The most
                                                  recent run failed.
- Improving: The most
                                                  recent run was successful, but there was at least
                                                  one failure in the previous nine runs.
- Stable: The most
                                                  recent run and previous runs were successful.
