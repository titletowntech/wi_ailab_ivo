# App Xchange for Contractors

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/getting-started/app-xchange-for-contractors
> Captured directly from rendered HTML: 2026-08-14

Follow this strategic framework to build and deploy custom
        automation workspaces and synchronize data across software systems.

With some exceptions, App Xchange
            for Contractors users will typically follow this basic roadmap to meet their individual
            business needs.

1. Configure, connect, and test your product connectors.
  - Add connectors and connections. For more
                                information, see [Connectivity - make sure to visit the specific section on the product you wish to connect](https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/connectors). You'll need to setup the connected product and enter credentials to communicate with App Xchange.
  - Add a cache write service and run an initial cache
                                write. For more information, see [Jobs and Schedules](https://help.trimble.com/doc/app-xchange/app-xchange/jobs-and-schedules).
  - Test and iterate.
2. Develop and customize your automation. For more information,
                      see [Flow Authoring](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/best-practices-for-flow-design).
  - Create a flow.
  - Add a schedule.
  - Test and iterate.
3. Deploy your automation. For more information, see [Create an Internal Integration Deployment](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-an-internal-integration-deployment).
4. Once your flows are moving data, monitor your data health
                      using the [Account Dashboard](https://help.trimble.com/doc/app-xchange/app-xchange/dashboards/account-dashboard), [Tasks](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-management/tasks), or [flow step emails](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-steps/email-flow-step).
