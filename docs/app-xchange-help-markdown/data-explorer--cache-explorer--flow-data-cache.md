# Flow Data Cache

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/data-explorer/cache-explorer/flow-data-cache
> Captured directly from rendered HTML: 2026-08-14

The Flow Data Explorer can be found when viewing a flow. The
        Flow Data Explorer works the same as Workspace Cache Explorer with a few tweaks.

You can select from all available resources in a parsed
                Quick Searches dropdown (A). You can filter the records by
                Modified Date (B). To
            filter by a property, select Add
                Filter (C) and select the desired property, operator, and value. Within
            the table header, you can show and hide any properties associated with the record
            (D).

For any records that are used in active flows, there is a dropdown
            menu that allows you to go that flow, run the flow using Run Now or view the flow run
            instances using View Runs (G).
            This dropdown has the same functionality as the Triggered Flows timeline of the
            record detail. If you select multiple records, you can select Run Selected (F) to run them all.
