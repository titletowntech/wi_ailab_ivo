# Remove Duplicates Flow Step

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-steps/remove-duplicates-flow-step
> Captured directly from rendered HTML: 2026-08-14

Use the ![Remove Duplicates flow step icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/ae2f2b47-c2f6-4d28-8f1c-7844b95dc2c5.svg) Remove Duplicates flow
                                        step to remove duplicate values from a list.

## Step Inputs

In the Edit Step menu, you can add details about the step configuration as
                needed for your flow.

- List: Enter an expression that points to the
                          list you want to remove duplicates from.

## Step Outputs

The Remove Duplicates flow step output is a new list containing
                the unique elements from the input list, with all duplicate entries removed.
