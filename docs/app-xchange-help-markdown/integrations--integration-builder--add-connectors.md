# Add Connectors

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-connectors
> Captured directly from rendered HTML: 2026-08-14

Integration builders that want to interface with a specific application's data must first add that application's connector to their integration.

    Your use
            account must have Integration
                Author permissions to complete this task.For more information, see [Connectors](https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/connectors).
1. Select ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder and open the appropriate integration.
2. Select the ![connectors icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/40226ac9-8020-4722-8766-d9586b0879c5.svg) Connectors tab then select the integration you want to add the
            connector to.
3. Select Add Connectors.App Xchange displays the Add Connectors window. Any connector already added to your integration will already be selected.
4. Select the Public Connectors or Account Owned Connectors tab as appropriate.
            Tip: Use the Search field if necessary to find the
              connector you want on the selected tab.
5. Choose which connectors you want to add to your integration.You can select more than one, and you can select them from both tabs.
6. When your connectors have been selected, choose Add Connector(s).
The connectors are added to your integration. They
      display on the connector details and related modules page. If you are building an integration,
      your next step may be to [Add Features](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features) that address
      your business needs.

If you've accidentally added a connector you do not
        want or need, you'll need to [contact support](https://info.trimble.com/en/knowledge/contact-support) as removing a connector is a protected
        ability.
