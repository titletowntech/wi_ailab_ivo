# Flow Activity Log Tab

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-management/flow-run-information/flow-activity-log-tab
> Captured directly from rendered HTML: 2026-08-14

The flow Activity Log records all changes made to the flow
        definition by all users.

To access a flow's Activity Log, open the flow and select Activity Log.

You can filter log entries by
                                activity, user, and date. Select an option from the dropdown list to
                                add the filter.

To add a general comment to the flow, select Add comment.

To see what was changed, expand an
                                item to view its details, or select Expand All.

                Each log entry includes:
- The date and time of change.
- The category of change.
- The user who made the change.
- A preview of the change.
- Any comments made on the change.Note: This only applies to
                                                    Flow Staged and
                                                    Flow Promoted
                                                  changes.
