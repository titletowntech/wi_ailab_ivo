# Edit a Workspace

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces/edit-a-workspace
> Captured directly from rendered HTML: 2026-08-14

Follow these steps to edit a workspace's details, including
        its name, icon, and notes.

        You must have the User
            or Admin role to complete these steps.
1. Open the workspace and select the
                          pencil icon next to its name.
2. Edit the workspace details as necessary.

                      Note: You cannot change a
                          workspace's URL part.

  1. To change the icon, select Add Icon.
                            Icons must meet the following
                                    requirements:
    - 256px x 256px
    - Non-grayscale brand color for the
                                          background
    - White for the foreground
    - 160px x 160px max foreground size
  2. To change the name field, enter a new name in the
                                    Name field.
  3. To add notes to a workspace, enter them in the
                                    Notes field.
  4. To change which account manages the workspace, select the account from
                                the Managing account dropdown.
3. Select Save.
All changes to the workspace are saved.
