# Workspace Dashboard

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/dashboards/workspace-dashboard
> Captured directly from rendered HTML: 2026-08-14

The workspace ![dashboard icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/80da103a-8f46-48f8-a076-613a3016a6ca.svg) Dashboard tab provides insights about your workspace data.
        Use the filters to sort the data you see in each widget and use this information to track
        down issues.

## Completed Flow Runs

The Completed Flow Runs
                widget displays data about recent flow run results. The graph displays a
                visualization of flow run results and statuses over time. The table displays flow
                details including flow name, time of the last finish, run status, and total runs.
                    Note: The Flow Trends widget does
                    not display data for flow runs that are queued or in progress.

Select a flow from the table to open the Runs page for that
                instance of the flow in your workspace. For information about other common filters,
                see [Dashboards](https://help.trimble.com/doc/app-xchange/app-xchange/dashboards).

The dashboard does not automatically refresh. To refresh the data in the widget,
                select the blue refresh icon.

## Schedule Health

The Schedule Health widget displays data about
                                schedule runs over the last 31 days. The graph displays a
                                visualization of the schedule and statuses over time. The table
                                displays schedule details including schedule name, time of the last
                                finish, health status, and the health trend of the last 10
                                runs.

Select the plus sign
                                next to the workspace to see the details of each schedule.

The dots are a quick glance at the last ten schedule runs.
                                Schedules being run as part of features in maintenance or onboarding
                                mode are tagged as such.

The Last
                                Finished column shows the date when the schedule was last
                                finished.

The Status column shows
                                the results of the last 10 available runs. The schedule can have
                                several statuses.

- Archived: The
                                                  schedule is no longer in use.
- Healthy: All of the
                                                  displayed runs were successful.
- Inactive: The
                                                  schedule is currently turned off.
- Unhealthy: At least
                                                  one of the displayed runs was unsuccessful.

The Trends column shows an at-a-glance look at
                                the last run.

- Degrading: The most
                                                  recent run failed.
- Improving: The most
                                                  recent run was successful, but there was at least
                                                  one failure in the previous nine runs.
- Stable: The most
                                                  recent run and previous runs were successful.
