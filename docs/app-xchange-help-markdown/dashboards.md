App Xchange
        features multiple ![dashboard icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/80da103a-8f46-48f8-a076-613a3016a6ca.svg) Dashboard pages that allow users to easily analyze data across the platform. They share a universal

## Filter Dashboard Graphs

All App Xchange dashboards use the same filters for detailed data analysis.

- Time range:
                      Filter the entire dashboard by one of the following time ranges: Last Hour, Last
                      4 Hours, Last 12 Hours, Today, Yesterday, Last 24 Hours, Last 7 Days, or Last 30
                      Days. You can also input a custom time range. If you choose this option, you
                      must select a start date and time and an end date and time.Note: All times are local
                      time.
- Increment:
                      Select a time interval to change the granularity of data shown on the graph.
                      Increments include 1 Minute, 5 Minutes, 15 Minutes, 1 Hour, 4 Hours, or 1 Day.
                          Note: The time range you select
                          impacts the available options in the increment
                          field.
- Run status: Filter the flow data in the graph by run status:
                      Success, Failed, Exception, Canceled,or any combination of these. Only the graph
                      is impacted by these run status filters—the table always displays all run
                      statuses.

## Sort Dashboard Tables

All App Xchange dashboards use the same sorting options for detailed data
                analysis.

- Last finished: Sort the data in the table
                      by the time the flow run finished. The table defaults to showing the last
                      finished flow run at the top.
- Successful, Failed,
                          Exception, Canceled: Sort the
                      data in the table by successful, failed, exception, and canceled runs.
