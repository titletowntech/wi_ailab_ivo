# Workspaces

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces
> Captured directly from rendered HTML: 2026-08-14

A workspace is where an integration lives, whether it is an integration product registered to the workspace or a custom integration built in the workspace.

A workspace is how App Xchange tenants (or separates) data. A team can collaborate on building flows and integrations and scheduling jobs within the workspace.

Accounts typically start with a single workspace. As your needs increase and you identify additional opportunities for automation and integrations, you can ask App Xchange support to separate them into multiple workspaces. This provides a greater level of control over what a workspace can do and who can collaborate within a workspace.

Use your workspace to add connectors and services to move data between external systems and the App Xchange platform. Add the flows to move and map data between connectors. You will also create the schedule to run the jobs that will trigger the flows.

Once you have run jobs for your integrations, the workspace hosts detailed views into cache history, actions, and flow runs for a more in-depth look at what the App Xchange platform is doing with that data. This is a powerful tool for troubleshooting data issues.

There are several types of workspaces.

           StandardA standard workspace is used to register integration products. Moves data
            from a single company between relevant systems. This includes customer workspaces, which
            are workspaces where an integration builder deploys an integration to a customer. For
            more information, see [Customer Workspaces](https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces/customer-workspaces).AutomationUsed to build custom integrations to fulfill specific client requests. Users
            must set up all connectors, flows, services, and schedules manually. Users cannot
            register an integration product here. For more information, see [Automation Workspaces](https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces/automation-workspaces).DevelopmentA development workspace is automatically created when you first create a new
            integration. It allows you to test components of the integration you are building to
            ensure it is functioning as expected. For more information, see [Development Workspaces](https://help.trimble.com/doc/app-xchange/app-xchange/administration/workspaces/development-workspaces).
