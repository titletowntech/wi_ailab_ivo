# Development Workspaces

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/development-workspaces
> Captured directly from rendered HTML: 2026-08-14

Development workspaces are a special workspace type that
      allows integration builders to test an integration to ensure it functions as
      expected.

A development workspace is automatically created when
         you first create a new integration. It is associated with the integration builder's account
         rather than the customer's.

To access workspaces, open ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder and select an integration. Select ![workspaces icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/476c5b53-43e4-4db2-8d78-2a882a193df2.svg) Development Workspaces.

To create an
            additional developmont workspace, select Create Development Workspace.

Your account must
            have the ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder permission to acess a development workspace. In
            general, you can start testing in your development workspace after adding [features](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features), [services](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features/add-services-to-a-feature), and
               [flows](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-features/add-flows-to-a-feature) to your
            integration.

Important: Do
            not use your development workspace to build an integration. Instead, develop the
            integration in the integration build and sync it to the development workspace for
            testing.

Development workspaces cannot be deleted.

To test in your development workspace:

1. Open ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder and select your integration.
2. Select ![workspaces icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/476c5b53-43e4-4db2-8d78-2a882a193df2.svg) Development Workspaces.
3. Select the development workspace to open it.
              The Development
                    Workspace opens.
4. Set the status and configurations of the different features you have added to the integration.
5. To sync the development workspace to the integration
                 definition, select Sync.
              This copies information from the features to the workspace.
6. Test and iterate.
