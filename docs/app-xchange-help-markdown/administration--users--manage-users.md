# Manage Users

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/users/manage-users
> Captured directly from rendered HTML: 2026-08-14

Only users with an administrator role can manage users.

Once a user has accepted their invitation and set up their App Xchange user, you can make changes to this user as needed. Over time, you may need to lock or restrict resources on your company account to limit some users' access.Note: Users must sign out and back in before any changes take effect.

## Edit User Information and Permissions

You can change a user's account information and roles. User information includes email address, name, and phone number.

1. Select ![users icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/48fc7c78-195d-498a-8318-185fda489821.svg) Users, then select the name or email of the
                      user.
                  You can use the Search field to find the user, if needed.
                  The Edit User page opens.
2. Update the necessary information.
3. Change the permissions, if needed.
4. Select Save.
The user information and permissions are updated the
            next time the user logs out then back in.

## Lock or Unlock a User

Locking a user prevents them from logging in or accessing secure API endpoints. Users can also be unlocked following the same steps. You cannot lock a guest user.

1. Select ![users icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/48fc7c78-195d-498a-8318-185fda489821.svg) Users, then select the name or email of the
                      user.
                  You can use the Search field to find the
                      user, if needed.
                  The Edit User page
                      opens.
2. Select Lock to lock the user out of their account. Alternatively, select Unlock to unlock a previously locked account. Select Yes in the confirmation window to confirm your choice.
The user account is locked or unlocked  the next time
            the user logs out then back in.

## Remove a Guest User

You can remove a guest user from your account by selecting the button. You cannot remove a non-guest user.

1. Select ![users icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/48fc7c78-195d-498a-8318-185fda489821.svg) Users, then select the name or email of the
                      user.
                  You can use the Search field to find the
                      user, if needed.
                  The Edit User page
                      opens.
2. Select Remove to lock the user out of their account.
                      Note: This does not delete their account.
The guest user is removed.
