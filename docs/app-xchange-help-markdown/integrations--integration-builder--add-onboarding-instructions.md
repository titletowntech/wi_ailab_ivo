# Add Onboarding Instructions

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-onboarding-instructions
> Captured directly from rendered HTML: 2026-08-14

After setting up the components of your integration definition, you can enter instructions in Markdown to help customers onboard this integration in their workspaces.

1. Select ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder and open the appropriate integration.
2. Select the ![instructions icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/73e1456d-ca0e-41ea-b41b-c2f88273504b.svg) Instructions tab.
          The Instructions page opens.
3. In the integration definition you are building, go to the Instructions page.  Start typing instructions in the Markdown window.
4. You can see your content in the Preview window. For assistance with syntax, see
        [Markdown Syntax](https://www.markdownguide.org/basic-syntax/).
5. Select Save.
6. To see the instructions, sync the integration definition with your workspace or development workspace.
7. Open that workspace and select the integration.  In the integration header, select Onboarding Instructions.
