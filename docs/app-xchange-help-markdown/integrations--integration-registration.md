# Integration Registration

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration
> Captured directly from rendered HTML: 2026-08-14

Integration registration is the process of deploying an
        integration product to a workspace, configuring its setup, and activating the integration
        resources you will use for that workspace.

If you have not created an integration, do that first. See [Integration Builder](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder)
            for details.

When registering an integration, complete the Integration Registration
            checklist:

1. Register the integration as follows:
  - Add the integration to your workspace: [Create an Internal Integration Deployment](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-an-internal-integration-deployment)
  - Add the integration to a customer's workspace: [Create a Customer Integration Deployment](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-a-customer-integration-deployment)
  - If a workspace has already been created for you:
                                    [Sync an Integration Registration](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/sync-an-integration-registration)
2. [Configure Connectors](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/configure-connectors)
3. [Onboard and Configure Features](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/onboard-and-configure-features)
4. [Populate Data for a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/populate-data-for-a-feature)
5. [Validate Data for a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/validate-data-for-a-feature)
6. [Run Flows for a Feature](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/run-flows-for-a-feature)
7. [Activate or Deactivate Features](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/activate-or-deactivate-features)
