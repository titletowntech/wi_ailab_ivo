# Add an Integration

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/add-an-integration
> Captured directly from rendered HTML: 2026-08-14

Adding a new integration to your account creates a developer workspace where you can design and iterate.

    Your use
            account must have Integration
                Author permissions to complete this task.
1. Navigate to the account where you want to add an
            integration.

            Note: An integration is owned by the account
              it is created on.
2. Select ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder.
          The Integration Builder opens.
3. Select Add Integration and choose the appropriate integration type.
4. Fill in the required fields.

  1. Name: Enter a name for the integration.
                Use the recommended naming convention, Connector 1 <> Connector
                    2, or, if data only flows for one way, Connector 1 >
                    Connector 2.
  2. Project Based: Off by
                  default.
                Toggle this option on if the integration will
                  occur between two different companies collaborating on a project.
  3. Connectors: Select the
                  connectors involved in the integration. Select the Plus sign to add another connector.
  4. Description: Optional.
                  Provide details about the integration.
5. Select Add Integration.
6. Open the new integration to add other components (such as Features) and continue building it out.

    A Development Workspace is
      automatically created for your integration. For more information, see [Development Workspaces](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/development-workspaces).
