# Shared Flows

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/shared-flows
> Captured directly from rendered HTML: 2026-08-14

If you want your flow to be used by another workspace or
        registered to an integration, you will need to mark it as
        Shared.

By default, a flow is only available to the workspace it was created in.
            Keeping flows Private to a workspace is ideal for testing or if
            custom logic is needed for a customer.

## Create a Shared Flow

Follow these steps to make a flow shareable.

        You must have the Flow
            Author account role to complete this task.
        When making a shared flow, consider what might change between all workspaces where
            that flow is used make those aspects [configurable](https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/using-configurations-in-flows).
1. From the Edit tab for your flow, select the
                          Edit button.
2. Toggle on the Shared
                      option.
3. Select Save.

## Make a Shared Flow Private

Disabling the Shared toggle for a flow only prevents your flow from being used in new
        workspaces. Follow these steps when you want to unshare a flow for all
        workspaces.

        You must have the Flow
            Author account role to complete this task.
1. From the Edit tab for your flow, select the
                          Edit button.
2. Select Archive.
This archives the flow for all other workspaces.
