# Create a Base Connection

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/connections/base-connections/create-a-base-connection
> Captured directly from rendered HTML: 2026-08-14

Base connections define specific connection details to be
        used for each registration of a given integration.

        You can only create a base connection for a connector that
            supports them.

1. Select ![connectors icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/40226ac9-8020-4722-8766-d9586b0879c5.svg) Connectors.
2. Under the appropriate connector, create a base
                      connection as follows:

  - To create a base connection when one
                            already exists, select the plus icon.
  - To create a base connection where none
                            exist, select Create a Base
                                Connection for the appropriate connector.

                      Note:
3. Enter a base connection name that explains what the base is intended to do.
                  Customers can change this name if they want.
4. Enter the connection details that you want to
                      pre-populate.
                  The connection details available depend on the connector and are all optional.
                      You can even create a base connection with no configured fields. Customers will
                      not be able to modify any fields you define.
5. Select Create.

        Your base connection is created.
