# Autodesk Forma Connector

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/app-connectors/autodesk-forma-connector
> Captured directly from rendered HTML: 2026-08-14

The Autodesk Forma (formerly Construction Cloud) connector
        enables App Xchange users to access and manage
        data across various Autodesk platforms.

The [Autodesk Forma](https://construction.autodesk.com/) connector provides a
            unified and consistent way to access data across BIM 360 Team, Fusion Team (formerly
            known as A360 Team), BIM 360 Docs, A360 Personal, and the Object Storage Service.

With this API, you can accomplish a number of workflows, including accessing a
            Fusion model in Fusion Team and getting an ordered structure of items, IDs, and
            properties for generating a bill of materials in a 3rd-party process. You might also
            want to superimpose a Fusion model and a building model to use in the viewer.

It supports data types including folders, projects, project users, RFIs, RFI
            attachments, RFI comments, specs, project specs, submittal items, submittal packages,
            and submittal item types.

Users can retrieve the above data types; add RFIs, comments, and attachments;
            create or update folders and items; and export PDF files.
