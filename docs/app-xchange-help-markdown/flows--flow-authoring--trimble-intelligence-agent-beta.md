# Trimble Intelligence Agent (Beta)

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/flows/flow-authoring/trimble-intelligence-agent-beta
> Captured directly from rendered HTML: 2026-08-14

The Trimble Intelligence Agent can answer your questions and
        modify flow steps directly within the App Xchange Flow Builder.

To use it, select the Trimble Intelligence (Beta) icon in the Edit
            Step pane of a new or existing flow step.

![Trimble Intelligence beta icon in the New Step drawer](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/43ca0553-18cf-477f-8c3c-4ee60dbe704b.png)

This beta release supports several core capabilities:

- AI-generated triggers and JavaScript code steps based on text
                      prompts.
- A side-by-side change preview that displays proposed
                      adjustments in a separate panel before they are applied.
- Contextual refinement so you can give follow-up instructions
                      to tweak a suggestion without re-explaining the entire goal.
- Platform and flow Q&A to help you understand what an
                      existing flow does.

            Note: This beta release focuses on
                single-step automation; multi-step generation and error troubleshooting will be
                added at a later date.
