# Customer Workspaces

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-builder/customer-workspaces
> Captured directly from rendered HTML: 2026-08-14

The Customer Workspaces page displays all customer workspaces that currently have that integration registered to them.

Select ![customer workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/2956fba6-a4ef-4061-ae71-8bfd4826f488.svg) Customer Workspaces to view the customer workspaces to which your account-owned integrations are
            registered.

![customer workspaces page](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/17043cee-d4d5-4785-84bb-8268e73b0933.png)

While customer workspaces are ultimately for customer use, they are managed by the
            account that originally created them. Customer workspaces are automatically created when
            you create a customer deployment.

Customer workspaces are created as a part of integration deployment.

For details, see [Create a Customer Integration Deployment](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-a-customer-integration-deployment).
