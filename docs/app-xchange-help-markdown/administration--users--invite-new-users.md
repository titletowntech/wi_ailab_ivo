# Invite New Users

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/administration/users/invite-new-users
> Captured directly from rendered HTML: 2026-08-14

Follow these steps to invite new users to your App Xchange account.

You must have the administrator role to invite users.Administrators can invite one or more new users to their company account. The invitation email allows recipients to register with App Xchange and enter their account information.
1. Select ![users icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/48fc7c78-195d-498a-8318-185fda489821.svg) Users then select Invite Users.
2. Enter the email address for each user. Separate
                      each user with a comma and a space.

  Each user entered must be assigned the same role and
                          additional permissions.
3. If you want to tag the user as a guest, select the checkbox next to These user(s) will be invited as guests, with limited permissions. This option is recommended when inviting users from outside your organization.

  Guest users cannot be assigned the administrator role.
4. Select the appropriate role and any additional
                      roles for the users. For more information, see [Permissions](https://help.trimble.com/doc/app-xchange/app-xchange/administration/users/permissions).
5. Select Send Invite.
 App Xchange invites each user. Users have two weeks to accept the invitation before it automatically expires. Once each user accepts, they must create a Trimble ID or link an existing one. They are then added to all workspaces that belong to your account.

## Revoke or Resend an Invitation

You can revoke an invitation if you send it to the wrong email address or if a recipient no longer needs to use App Xchange. You can resend an invitation using the same steps.

1. Select ![users icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/48fc7c78-195d-498a-8318-185fda489821.svg) Users then select the Invites tab.
2. Select the email address of the invitation you want to revoke or resend.
                      Tip: Select Show All? to display
                          expired invitations.
3. Choose Revoke or Resend. Optionally, you may change the role and account permissions before resending the invitation.
App Xchange resends or revokes the invitation.
