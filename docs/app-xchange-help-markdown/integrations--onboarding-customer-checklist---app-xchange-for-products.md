# Onboarding Customer Checklist - App Xchange for Products

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/onboarding-customer-checklist---app-xchange-for-products
> Captured directly from rendered HTML: 2026-08-14

Once you have built an integration and are ready to deploy
    this integration to a customer, follow these steps to create and connect a customer
    workspace.

    Before you complete this task, ensure you have followed the
      steps in the [App Xchange for
        Products](https://help.trimble.com/doc/app-xchange/app-xchange/getting-started/app-xchange-for-products).You must complete a new form for each new
      deployment.
1. Engage with the customer.

  Notify the customer that an App Xchange invitation is coming. Provide documentation outlining the
              technical prerequisites they must meet to prepare their system.
2. Issue the integration invitation.
          For instructions, see [Create a Customer Integration Deployment](https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-registration/create-a-customer-integration-deployment).
           A deployment workspace is created for the customer. The customer is
            invited.
3. Prompt your customer to input their credentials and
            configure the connectors.
          If required, you can perform these steps on behalf of the customer.
4. Configure the workspace.

  Enable features, set configurations, and run schedules to populate the cache and get
              the data state ready to activate the integration.

  The customer workspace is
      connected and configured. You can view and manage the workspace in ![customer workspace icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/2956fba6-a4ef-4061-ae71-8bfd4826f488.svg) Customer Workspaces.
