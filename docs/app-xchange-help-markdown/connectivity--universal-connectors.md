# Universal Connectors

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/universal-connectors
> Captured directly from rendered HTML: 2026-08-14

The ability to interact directly with external applications is
        a key part of the integrations built on the platform, in which data is pulled from and
        delivered to those applications. The connector is what App Xchange uses to do
        that.

Each connector depends on a unique configuration to enable interaction
            with the connected application or product. Below is a list of universal connectors.
            Unlike app connectors, universal connectors are configured at both the Connector and
            Service level.

- [S/FTP Connector](https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/universal-connectors/sftp-connector)
- [File Connector](https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/universal-connectors/file-connector)
- [HTTP Connector](https://help.trimble.com/doc/app-xchange/app-xchange/connectivity/universal-connectors/http-connector)
