# Integration Activity Log

> Source: https://help.trimble.com/doc/app-xchange/app-xchange/integrations/integration-activity-log
> Captured directly from rendered HTML: 2026-08-14

An integration's ![activity log icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/65a729db-df28-40c9-a8b3-4bb1fcfab5c8.svg) Activity Log tab records all changes made to the integration definition by all users. You can also use
        this log to get more information on why a sync is failing.

To access the integration Activity Log, select ![integration builder icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/1c7a8835-4b43-44d9-b185-65f81e433104.svg) Integration Builder and open the integration. Then select the
            integration's ![activity log icon](https://help.trimble.com/dist/suf/product-guides/heretto/app-xchange/en/app-xchange/65a729db-df28-40c9-a8b3-4bb1fcfab5c8.svg) Activity Log tab.

You can filter log entries by
                                activity, user, and date. Select an option from the dropdown list to
                                add the filter.

To see what was changed, expand an
                                item to view its details, or select Expand All.

        Each log entry includes:
- The date and time of change.
- The category of change.
- The user who made the change.
- A preview of the change.
